Haftung

Die Haftung wird nur im gesetzlich zulässigen Umfang ausgeschlossen; zwingende gesetzliche Haftung bleibt vorbehalten.

Datenschutz beim Seitenaufruf

Die Website wird über GitHub Pages bereitgestellt. Dabei können technisch notwendige Verbindungsdaten verarbeitet werden. Die Seiten laden derzeit Schriftarten über Google Fonts; Themenseiten laden MathJax über jsDelivr. Dadurch können insbesondere IP-Adresse, Zeitpunkt und Browserinformationen an diese Anbieter übermittelt werden. Eigene Analyse- oder Werbetracker werden nicht eingesetzt.

Datenschutz beim Feedback

Beim Absenden des Feedbackformulars werden die eingegebenen Angaben und ein optionaler Screenshot über Google Apps Script verarbeitet. Die Daten dienen ausschliesslich der Bearbeitung der Rückmeldung und werden nach Abschluss, spätestens nach 12 Monaten, gelöscht. Name und E-Mail-Adresse sind freiwillig.

Betroffenenrechte

Für Auskunft, Berichtigung oder Löschung der eigenen Angaben genügt eine Nachricht über das Formular auf der Seite Kontakt & Feedback. Damit eine Antwort möglich ist, im freiwilligen Feld eine E-Mail-Adresse angeben — ohne Kontaktangabe kann eine Rückmeldung nicht beantwortet werden.
