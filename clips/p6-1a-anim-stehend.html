Die Erkenntnisse zur Animation «Laufend oder stehend?»
\(\text{hin: }A = 3\,\mathrm{cm}\qquad\text{zurück: }A = 3\,\mathrm{cm}\)
Beide mit \(c = 2.0\,\mathrm{m/s}\) und derselben Frequenz.
\(\lambda = \frac{c}{f} = \frac{2.0\,\mathrm{m/s}}{1.00\,\mathrm{Hz}} = 2.00\,\mathrm{m}\)
Das Muster wandert nach rechts.
Jedes Teilchen schwingt mit \(A = 3\,\mathrm{cm}\).
\(\text{Knotenabstand} = \frac{\lambda}{2} = \frac{2.00\,\mathrm{m}}{2} = 1.00\,\mathrm{m}\)
Das Muster wandert nicht mehr, es schwingt am Ort.
Bei \(s = 1.5\,\mathrm{m}\): Knoten, das Teilchen ruht.
\(A_\text{Bauch} = 2A = 2\cdot 3\,\mathrm{cm} = 6\,\mathrm{cm}\)
Zwischen den Knoten liegen die Bäuche.
Bei \(s = 2.0\,\mathrm{m}\): Bauch, doppelte Amplitude.
\(\lambda = \frac{c}{f} = \frac{2.0\,\mathrm{m/s}}{1.50\,\mathrm{Hz}} = 1.33\,\mathrm{m}\)
Die Knoten rücken zusammen: \(\lambda/2 = 0.67\,\mathrm{m}\).
Umgekehrt: \(\lambda = 2\cdot\) Knotenabstand.
Hin plus zurück ergibt eine stehende Welle.
\(\text{Knotenabstand} = \frac{\lambda}{2}\qquad A_\text{Bauch} = 2A\)
Knoten ruhen, das Muster wandert nicht.
