Die Erkenntnisse zur Animation «Eigenschwingungen der eingespannten Saite»
\(L = 2.00\,\mathrm{m}\qquad c = 12\,\mathrm{m/s}\)
An beiden Enden eingespannt: Dort muss ein Knoten sitzen.
\(\lambda_1 = \frac{2L}{1} = 2\cdot 2.00\,\mathrm{m} = 4.00\,\mathrm{m}\)
\(f_1 = \frac{c}{\lambda_1} = \frac{12\,\mathrm{m/s}}{4.00\,\mathrm{m}} = 3.00\,\mathrm{Hz}\)
Ein Bauch in der Mitte, Knoten nur an den Enden.
\(\lambda_3 = \frac{2L}{3} = \frac{2\cdot 2.00\,\mathrm{m}}{3} = 1.33\,\mathrm{m}\)
\(f_3 = 3\cdot\frac{c}{2L} = 3\cdot 3.00\,\mathrm{Hz} = 9.00\,\mathrm{Hz}\)
Drei Bäuche, zwei innere Knoten.
\(f_3 = 3\cdot\frac{c}{2L} = 3\cdot\frac{12\,\mathrm{m/s}}{2\cdot 1.00\,\mathrm{m}} = 18.0\,\mathrm{Hz}\)
Halbe Länge: \(\lambda_3 = 0.67\,\mathrm{m}\), doppelte Frequenz.
So funktioniert Greifen: Es verkürzt die Saite.
\(f_1 = \frac{c}{2L} = \frac{429\,\mathrm{m/s}}{2\cdot 0.65\,\mathrm{m}} = 330.0\,\mathrm{Hz}\)
