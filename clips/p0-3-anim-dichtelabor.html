\(\fd{\rho} = \frac{m}{\fa{V}}\)
Die Dichte ist nie direkt ablesbar.
\(\fa{V} = V_2 - V_1 = 120\,\mathrm{ml} - 50\,\mathrm{ml} = \fa{70\,\mathrm{cm^3}}\)
\(\fd{\rho} = \frac{m}{\fa{V}} = \frac{200\,\mathrm{g}}{\fa{70\,\mathrm{cm^3}}} = \fd{2.86\,\mathrm{g/cm^3}}\)
Passende Gesteine: Basalt oder Gneis.
\(\fd{\rho} = \frac{m}{\fa{V}} = \frac{189\,\mathrm{g}}{\fa{70\,\mathrm{cm^3}}} = \fd{2.70\,\mathrm{g/cm^3}}\)
Granit und Aluminium: beide \(2.7\,\mathrm{g/cm^3}\).
Die Dichte legt den Stoff nicht eindeutig fest.
\(\fa{V} = a\cdot b\cdot c = 4.0\,\mathrm{cm}\cdot 3.0\,\mathrm{cm}\cdot 2.0\,\mathrm{cm} = \fa{24.0\,\mathrm{cm^3}}\)
\(\fd{\rho} = \frac{m}{\fa{V}} = \frac{64.8\,\mathrm{g}}{\fa{24.0\,\mathrm{cm^3}}} = \fd{2.70\,\mathrm{g/cm^3}}\)
