\(\fa{F_1} = \fc{F_2}\)
Eine gespannte Feder drückt zwei Wagen auseinander.
\(\fa{\vec F_1} = -\fc{\vec F_2}\)
Gleich gross, entgegengesetzt: actio gleich reactio.
Sie wirken auf verschiedene Wagen und heben sich nicht auf.
\(\frac{\fa{a_1}}{\fc{a_2}} = \frac{F/\fa{m_1}}{F/\fc{m_2}} = \frac{\fc{m_2}}{\fa{m_1}} = \frac{\fc{4.0\,\mathrm{kg}}}{\fa{2.0\,\mathrm{kg}}} = 2\)
\(\fa{v_1} = 3.00\,\mathrm{m/s}\) ; \(\fc{v_2} = 1.50\,\mathrm{m/s}\): doppelt so schnell.
Halbe Masse, doppelte Beschleunigung.
\(\frac{\fa{a_1}}{\fc{a_2}} = \frac{\fc{m_2}}{\fa{m_1}} = \frac{\fc{3.0\,\mathrm{kg}}}{\fa{3.0\,\mathrm{kg}}} = 1\)
\(\fa{v_1} = \fc{v_2} = 2.00\,\mathrm{m/s}\): spiegelbildlich.
Keiner der beiden ist der, der drückt.
\(\fa{m_1}\cdot\fa{v_1} = \fa{1.0\,\mathrm{kg}}\cdot\fa{6.00\,\mathrm{m/s}} = 6.00\,\mathrm{kg\cdot m/s}\)
\(\fc{m_2}\cdot\fc{v_2} = \fc{6.0\,\mathrm{kg}}\cdot\fc{1.00\,\mathrm{m/s}} = 6.00\,\mathrm{kg\cdot m/s}\)
Gleiche Kraft, gleich lange: gleiches Produkt.
