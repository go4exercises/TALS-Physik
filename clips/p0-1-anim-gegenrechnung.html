Wo treffen sich die Velos?
Die Erkenntnisse zur Animation «Gegenrechnung — Treffpunkt von links und von rechts»
\(t = \frac{d}{v_A + v_B}\)
Beim Aufeinanderzufahren addieren sich die Tempi.
\(t = \frac{d}{v_A + v_B} = \frac{300\,\mathrm{m}}{12\,\mathrm{m/s} + 8\,\mathrm{m/s}} = 15\,\mathrm{s}\)
Der Schnittpunkt der Geraden ist der Treffpunkt.
\(x = v_A\cdot t = 12\,\mathrm{m/s}\cdot 15\,\mathrm{s} = \fc{180\,\mathrm{m}}\)
\(x = d - v_B\cdot t = 300\,\mathrm{m} - 8\,\mathrm{m/s}\cdot 15\,\mathrm{s} = \fc{180\,\mathrm{m}}\)
Beide Wege stimmen überein.
\(t = \frac{d}{v_A} = \frac{300\,\mathrm{m}}{12\,\mathrm{m/s}} = 25\,\mathrm{s}\quad\fd{\text{(falsch)}}\)
\(x_B = 300\,\mathrm{m} - 8\,\mathrm{m/s}\cdot 25\,\mathrm{s} = \fd{100\,\mathrm{m}}\;\ne\;\fd{300\,\mathrm{m}}\)
Unterschied \(200\,\mathrm{m}\): Hier stimmt etwas nicht.
\(t = \frac{300\,\mathrm{m}}{18\,\mathrm{m/s} + 6\,\mathrm{m/s}} = 12.5\,\mathrm{s}\)
\(x = v_A\cdot t = 18\,\mathrm{m/s}\cdot 12.5\,\mathrm{s} = \fc{225\,\mathrm{m}}\)
Von rechts: \(300\,\mathrm{m} - 6\,\mathrm{m/s}\cdot 12.5\,\mathrm{s} = 225\,\mathrm{m}\)
Zwei Wege, ein Ergebnis.
\(v_A\cdot t = d - v_B\cdot t\)
Weicht die Gegenrechnung ab, ist sicher etwas falsch.
