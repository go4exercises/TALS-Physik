Dieselbe Kraft, ganz verschiedene Wirkung
\(p = \frac{\fa{F}}{\fb{A}}\)
Nicht die Kraft entscheidet, sondern die Fläche darunter.
\(p = \frac{\fa{F}}{\fb{A}} \qquad [\,p\,] = \frac{\mathrm{N}}{\mathrm{m}^2} = \mathrm{Pa}\)
Die Kraft steht dabei senkrecht auf der Fläche.
Ein Pascal ist winzig: Ein Blatt Papier drückt mit knapp 1 Pa auf den Tisch.
\(\text{Sohlen:}\quad p = \frac{\fa{589\,\mathrm{N}}}{\fb{0.030\,\mathrm{m}^2}} = \fc{19.6\,\mathrm{kPa}}\)
\(\text{Absätze:}\quad p = \frac{\fa{589\,\mathrm{N}}}{\fb{0.00020\,\mathrm{m}^2}} = \fd{2.95\,\mathrm{MPa}}\)
Dieselbe Person, 150-facher Druck — allein wegen der Fläche.
\(1\,\mathrm{bar} = \fc{10^{5}}\,\mathrm{Pa} = 1000\,\mathrm{hPa}\)
\(\text{Luftdruck} \approx 1\,\mathrm{bar} = 1013\,\mathrm{hPa}\)
Der Wetterbericht nennt Hektopascal, die Werkstatt bar — dieselbe Grösse.
\(\text{an einer Stelle: } \fb{p} \text{ nach } \fa{\text{allen Seiten gleich}}\)
Auf jede Wand steht er senkrecht — gleich, wie sie liegt.
Darum wird ein Ballon rundum prall und nicht nur oben.
