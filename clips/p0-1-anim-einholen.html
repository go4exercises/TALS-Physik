Die Erkenntnisse zur Animation «Einholproblem»
\(\fa{s_A} = v_A\cdot t\qquad s_B = d + v_B\cdot t\)
Einholen heisst: gleicher Ort zur gleichen Zeit.
\(t^* = \frac{d}{v_A - v_B} = \frac{40\,\mathrm{m}}{5.0\,\mathrm{m/s} - 3.0\,\mathrm{m/s}} = 20\,\mathrm{s}\)
\(s^* = v_A\cdot t^* = 5.0\,\mathrm{m/s}\cdot 20\,\mathrm{s} = 100\,\mathrm{m}\)
\(t^* = \frac{40\,\mathrm{m}}{3.5\,\mathrm{m/s} - 3.0\,\mathrm{m/s}} = \frac{40\,\mathrm{m}}{0.5\,\mathrm{m/s}} = 80\,\mathrm{s}\)
Kleine Differenz: grosse Einholzeit.
\(v_A - v_B = 3.0\,\mathrm{m/s} - 3.0\,\mathrm{m/s} = 0\)
Parallele Geraden: kein Treffpunkt.
Die Formel gilt nur für \(v_A \gt v_B\).
\(t^* = \frac{60\,\mathrm{m}}{5.0\,\mathrm{m/s} - 3.0\,\mathrm{m/s}} = 30\,\mathrm{s}\)
\(s^* = 5.0\,\mathrm{m/s}\cdot 30\,\mathrm{s} = 150\,\mathrm{m}\)
Erst die Bedingung, dann die Formel.
\(t^* = \frac{d}{v_A - v_B}\quad (v_A \gt v_B)\)
Bei \(v_A \le v_B\): kein Einholen.
