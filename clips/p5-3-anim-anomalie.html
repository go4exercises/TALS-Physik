Die Erkenntnisse zur Animation «Dichte von Wasser über der Temperatur»
\(\fd{\rho}\;\text{bei}\;{-20}\,^\circ\mathrm{C}\le\fc{\vartheta}\le 20\,^\circ\mathrm{C}\)
Links die Dichtekurve, rechts ein See im Winter.
\(\fd{\rho}(\fc{20\,^\circ\mathrm{C}}) = \fd{998.2\,\mathrm{kg/m^3}}\)
Beim Abkühlen steigt die Dichte zuerst an.
Die Achse oben reicht nur über \(2.4\,\mathrm{kg/m^3}\): stark gestreckt.
\(\fd{\rho}(\fc{4\,^\circ\mathrm{C}}) = \fd{1000.0\,\mathrm{kg/m^3}}\)
Das Maximum: Dichter wird Wasser nie.
Im See sinkt dieses Wasser an den Grund.
\(\fd{\rho}(\fc{1\,^\circ\mathrm{C}}) = \fd{999.9\,\mathrm{kg/m^3}}\)
Unter \(4\,^\circ\mathrm{C}\) wird Wasser wieder leichter.
Es bleibt oben, im See in der Schicht von 1 bis \(2\,^\circ\mathrm{C}\).
\(\fd{\rho}(\fc{-5\,^\circ\mathrm{C}}) = \fd{917.7\,\mathrm{kg/m^3}}\)
\(\frac{V_e}{V} = \frac{\fd{\rho_\text{Eis}}}{\rho_\text{W}} = \frac{\fd{917.7\,\mathrm{kg/m^3}}}{999.9\,\mathrm{kg/m^3}} = 91.8\,\%\)
