Die Erkenntnisse zur Animation «Woher die Heizwärme kommt»
\(\fd{Q_\text{warm}} = \fa{E_\text{el}} + \fc{Q_\text{Umg}}\)
Leistungszahl: \(\text{COP} = \frac{\fd{Q_\text{warm}}}{\fa{E_\text{el}}}\)
\(\fd{Q_\text{warm}} = \text{COP}\cdot\fa{E_\text{el}} = 3.5\cdot\fa{1.0\,\mathrm{kWh}} = \fd{3.5\,\mathrm{kWh}}\)
\(\fc{Q_\text{Umg}} = \fd{Q_\text{warm}} - \fa{E_\text{el}} = \fd{3.5\,\mathrm{kWh}} - \fa{1.0\,\mathrm{kWh}} = \fc{2.5\,\mathrm{kWh}}\)
Der grüne Pfeil ist gratis: Umgebungswärme.
\(\fd{Q_\text{warm}} = \text{COP}\cdot\fa{E_\text{el}} = 2.0\cdot\fa{1.0\,\mathrm{kWh}} = \fd{2.0\,\mathrm{kWh}}\)
\(\fc{Q_\text{Umg}} = \fd{Q_\text{warm}} - \fa{E_\text{el}} = \fd{2.0\,\mathrm{kWh}} - \fa{1.0\,\mathrm{kWh}} = \fc{1.0\,\mathrm{kWh}}\)
Strom und Umgebung liefern je die Hälfte.
\(\fd{Q_\text{warm}} = \text{COP}\cdot\fa{E_\text{el}} = 5.0\cdot\fa{1.0\,\mathrm{kWh}} = \fd{5.0\,\mathrm{kWh}}\)
\(\frac{\fa{E_\text{el}}}{\fd{Q_\text{warm}}} = \frac{\fa{1.0\,\mathrm{kWh}}}{\fd{5.0\,\mathrm{kWh}}} = 20\,\%\)
Achtzig Prozent kommen aus der Umgebung.
\(\fd{Q_\text{warm}} = \text{COP}\cdot\fa{E_\text{el}} = 4.0\cdot\fa{1.0\,\mathrm{kWh}} = \fd{4.0\,\mathrm{kWh}}\)
\(\fa{E_\text{el}} + \fc{Q_\text{Umg}} = \fa{1.0\,\mathrm{kWh}} + \fc{3.0\,\mathrm{kWh}} = \fd{4.0\,\mathrm{kWh}}\)
