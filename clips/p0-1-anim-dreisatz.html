Die Erkenntnisse zur Animation «Dreisatz interaktiv — Äpfel einkaufen»
\(3\,\mathrm{kg}\;\longrightarrow\;7.50\,\mathrm{CHF}\)
Gegeben ist ein Punkt, gesucht ein zweiter.
\(p = \frac{K}{\fa{m}} = \frac{7.50\,\mathrm{CHF}}{\fa{3\,\mathrm{kg}}} = \fd{2.50\,\mathrm{CHF/kg}}\)
Ein Kilogramm kostet 2.50 CHF: der Preis.
\(K = \fa{m}\cdot p = \fa{5.0\,\mathrm{kg}}\cdot 2.50\,\mathrm{CHF/kg} = \fd{12.50\,\mathrm{CHF}}\)
Fünf Kilogramm kosten 12.50 CHF.
\(K = \fa{m}\cdot p = \fa{6.0\,\mathrm{kg}}\cdot 2.50\,\mathrm{CHF/kg} = \fd{15.00\,\mathrm{CHF}}\)
Doppelt so viel wie 3 kg: doppelt so teuer.
\(\frac{K}{\fa{m}} = \fd{2.50\,\mathrm{CHF/kg}}\quad\text{für jeden Punkt}\)
Alle Punkte liegen auf einer Geraden durch den Ursprung.
Mit Mengenrabatt: kein Dreisatz.
Erst auf eins zurück, dann hochrechnen.
\(p = \frac{K}{\fa{m}}\qquad K = \fa{m}\cdot p\)
Nur wenn die Grössen proportional sind.
