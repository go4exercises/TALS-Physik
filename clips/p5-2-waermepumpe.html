Vier aus eins?
Was die Leistungszahl einer Wärmepumpe wirklich sagt
\(\fa{1\,\mathrm{kWh}}\ \text{Strom} \;\longrightarrow\; \fd{4\,\mathrm{kWh}}\ \text{Wärme}\)
Vierhundert Prozent Wirkungsgrad? So sieht es aus.
\(\text{COP} = \frac{\fd{Q_\text{warm}}}{\fa{E_\text{el}}}\)
Bei COP gleich vier werden aus einer Kilowattstunde vier.
Gezählt wird nur der Strom — weil nur er bezahlt werden muss.
\(\fa{1\,\mathrm{kWh}}\ \text{Strom} + \fb{3\,\mathrm{kWh}}\ \text{Umgebung} = \fd{4\,\mathrm{kWh}}\ \text{Heizwärme}\)
\(\fa{1\,\mathrm{kWh}}\ \text{Strom} + \fb{3\,\mathrm{kWh}}\ \text{Umgebung} = \fd{4\,\mathrm{kWh}}\ \text{Heizwärme}\)
Die Energiebilanz geht genau auf — nichts wird erzeugt.
Eine Wärmepumpe ist keine Energiequelle, sondern ein Transportmittel.
\(\fb{\eta} = \frac{\fd{4}}{\fa{1} + \fb{3}} \lt 1 \qquad \text{aber} \qquad \text{COP} = \frac{\fd{4}}{\fa{1}} = 4\)
Zwei Verhältnisse, zwei Nenner — nur einer zählt alles.
Eine Leistungszahl über eins ist erlaubt, ein Wirkungsgrad über eins nie.
\(\text{COP}_\text{max} = \frac{\fd{T_\text{warm}}}{\fd{T_\text{warm}} - \fb{T_\text{kalt}}} = \frac{308\,\mathrm{K}}{308\,\mathrm{K} - 273\,\mathrm{K}} = \fc{8.8}\)
Bei minus zehn Grad draussen sinkt die Grenze auf 6.8.
Am kältesten Tag arbeitet sie am schlechtesten — genau dann, wenn man sie am meisten braucht.
