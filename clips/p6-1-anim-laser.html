Die Erkenntnisse zur Animation «Photon-Emission und Laserprinzip»
\(\fd{\Delta E} = E_2 - E_1 = h\cdot\fb{f}\)
Modell: Die Bahnen stehen für Energieniveaus.
\(\text{Anregen: } E_1 \longrightarrow E_2\)
Grüner Pfeil: Energie wird zugeführt.
Das Elektron sitzt noch auf \(E_1\), dem tieferen Niveau.
\(\fd{\Delta E} = E_2 - E_1\)
Das angeregte Atom hat \(\fd{\Delta E}\) mehr Energie.
Der Zustand hält nur kurz.
Beispiel: \(\fd{\Delta E} = 2.00\,\mathrm{eV} = 3.204\cdot10^{-19}\,\mathrm{J}\)
\(\fa{\lambda} = \frac{h\cdot c}{\fd{\Delta E}} = \frac{6.626\cdot10^{-34}\,\mathrm{J\cdot s}\cdot 2.998\cdot10^{8}\,\mathrm{m/s}}{\fd{3.204\cdot10^{-19}\,\mathrm{J}}} = \fa{620\,\mathrm{nm}}\)
Die Niveaudifferenz legt die Farbe fest.
\(\text{1 Photon} \longrightarrow \text{2 gleiche Photonen}\)
Stimulierte Emission: gleiche Frequenz, Richtung, Phase.
Laserlicht: einfarbig, kohärent, gebündelt.
Ein Photon trägt genau die Niveaudifferenz.
