Die Erkenntnisse zur Animation «Boyle-Mariotte und Amontons»
\(\fa{p}\cdot\fb{V} = \text{konst.}\qquad \frac{\fa{p}}{\fc{T}} = \text{konst.}\)
Einmal bleibt \(\fc{T}\) fest, einmal \(\fb{V}\).
\(\fa{p} = \frac{\fa{p}\cdot\fb{V}}{\fb{V}} = \frac{6.0\,\mathrm{bar\cdot l}}{\fb{2.0\;\mathrm{l}}} = \fa{3.00\,\mathrm{bar}}\)
Fest ist das Produkt: \(\fa{p}\cdot\fb{V} = 6.0\,\mathrm{bar\cdot l}\).
Bedingung: \(\fc{T}\) konstant, feste Gasmenge.
\(\fa{p} = \frac{\fa{p}\cdot\fb{V}}{\fb{V}} = \frac{6.0\,\mathrm{bar\cdot l}}{\fb{4.0\;\mathrm{l}}} = \fa{1.50\,\mathrm{bar}}\)
Doppeltes Volumen, halber Druck: eine Hyperbel.
Sie nähert sich den Achsen, erreicht sie aber nie.
\(\fa{p} = \frac{\fa{p}}{\fc{T}}\cdot\fc{T} = \frac{1}{300}\,\mathrm{bar/K}\cdot\fc{300\,\mathrm{K}} = \fa{1.00\,\mathrm{bar}}\)
Fest ist der Quotient \(\fa{p}/\fc{T}\).
Bedingung: \(\fb{V}\) konstant, feste Gasmenge.
\(\fa{p} = \frac{\fa{p}}{\fc{T}}\cdot\fc{T} = \frac{1}{300}\,\mathrm{bar/K}\cdot\fc{400\,\mathrm{K}} = \fa{1.33\,\mathrm{bar}}\)
Ein Drittel mehr Temperatur, ein Drittel mehr Druck.
Die Gerade zielt auf \(0\,\mathrm{K}\), den absoluten Nullpunkt.
Temperatur fest: Hyperbel. Volumen fest: Ursprungsgerade.
\(\fa{p}\cdot\fb{V} = \text{konst.}\;(\fc{T}\;\text{fest})\qquad \frac{\fa{p}}{\fc{T}} = \text{konst.}\;(\fb{V}\;\text{fest})\)
Beide gelten für ein ideales Gas mit fester Gasmenge.
