Wie viel trägt das Wasser?
Die Erkenntnisse zur Animation «Auftriebskraft beim Eintauchen»
\(\fc{F_A} = \rho_\text{Fl}\cdot \fa{V_e}\cdot g\)
Ein Holzwürfel, \(10\,\mathrm{cm}\) Kante, taucht Stück für Stück ein.
\(\fd{F_G} = \rho_\text{Holz}\cdot V\cdot g\)
\({}= 700\,\mathrm{kg/m^3}\cdot 0.00100\,\mathrm{m^3}\cdot 9.81\,\mathrm{m/s^2} = \fd{6.87\,\mathrm{N}}\)
Noch kein Auftrieb: Die Waage zeigt das ganze Gewicht.
\(\fc{F_A} = \rho_\text{W}\cdot \fa{V_e}\cdot g\)
\({}= 1000\,\mathrm{kg/m^3}\cdot \fa{0.000600\,\mathrm{m^3}}\cdot 9.81\,\mathrm{m/s^2} = \fc{5.89\,\mathrm{N}}\)
\(600\,\mathrm{cm^3}\) Wasser verdrängt: \(0.60\,\mathrm{kg}\), deren Gewicht trägt.
Waage: \(\fd{F_G} - \fc{F_A} = 6.87\,\mathrm{N} - 5.89\,\mathrm{N} = 0.98\,\mathrm{N}\)
\(\fc{F_A} = \rho_\text{W}\cdot \fa{V_e}\cdot g\)
\({}= 1000\,\mathrm{kg/m^3}\cdot \fa{0.000700\,\mathrm{m^3}}\cdot 9.81\,\mathrm{m/s^2} = \fc{6.87\,\mathrm{N}}\)
\(\fc{F_A} = \fd{F_G}\): Das Wasser trägt den ganzen Würfel.
Frei schwimmend läge er genau so tief: \(7\) von \(10\,\mathrm{cm}\).
\(\fc{F_A} = \rho_\text{W}\cdot \fa{V}\cdot g\)
\({}= 1000\,\mathrm{kg/m^3}\cdot \fa{0.00100\,\mathrm{m^3}}\cdot 9.81\,\mathrm{m/s^2} = \fc{9.81\,\mathrm{N}}\)
Tiefer eintauchen ändert nichts: Die Kurve wird waagrecht.
Halter drückt: \(\fc{F_A} - \fd{F_G} = 9.81\,\mathrm{N} - 6.87\,\mathrm{N} = 2.94\,\mathrm{N}\)
Auftrieb = Gewicht des verdrängten Wassers
\(\fc{F_A} = \rho_\text{Fl}\cdot \fa{V_e}\cdot g\)
Ganz untergetaucht ist \(\fa{V_e} = V\): Der Auftrieb bleibt konstant.
