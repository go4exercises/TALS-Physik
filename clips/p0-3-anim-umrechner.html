\(\mathrm{kg/m^3}\quad \mathrm{g/cm^3}\quad \mathrm{kg/l}\quad \mathrm{t/m^3}\quad \mathrm{g/l}\)
Umgerechnet wird über die Grundeinheit \(\mathrm{kg/m^3}\).
\(1\,\frac{\mathrm{g}}{\mathrm{cm^3}} = \frac{10^{-3}\,\mathrm{kg}}{10^{-6}\,\mathrm{m^3}} = 1000\,\frac{\mathrm{kg}}{\mathrm{m^3}}\)
\(2.7\,\frac{\mathrm{g}}{\mathrm{cm^3}} = 2.7\cdot 1000\,\frac{\mathrm{kg}}{\mathrm{m^3}} = \fd{2700\,\frac{\mathrm{kg}}{\mathrm{m^3}}}\)
Tausendstel durch Millionstel: Faktor 1000.
\(1\,\mathrm{g/cm^3} = 1\,\mathrm{kg/l} = 1\,\mathrm{t/m^3}\)
\(1\,\mathrm{g/l} = 1\,\mathrm{kg/m^3}\)
Drei Namen, ein Zahlenwert.
\(917\,\frac{\mathrm{kg}}{\mathrm{m^3}} = \frac{917}{1000}\,\frac{\mathrm{g}}{\mathrm{cm^3}} = \fd{0.917\,\frac{\mathrm{g}}{\mathrm{cm^3}}}\)
