\(\fd{W} = \fa{F}\cdot s\cdot\cos\alpha\)
Ein Schlitten, \(50\,\mathrm{N}\) Zugkraft, \(2.0\,\mathrm{m}\) Weg.
\(\fd{W} = \fa{F}\cdot s\cdot\cos\alpha = \fa{50\,\mathrm{N}}\cdot 2.0\,\mathrm{m}\cdot\cos 0^\circ = \fd{100\,\mathrm{J}}\)
Das grüne Rechteck: Kraft mal Weg, Höhe mal Breite.
Die Einheit passt: \(1\,\mathrm{N}\cdot 1\,\mathrm{m} = 1\,\mathrm{J}\).
\(\fd{W} = \fa{F}\cdot s\cdot\cos\alpha = \fa{50\,\mathrm{N}}\cdot 2.0\,\mathrm{m}\cdot\cos 60^\circ = \fd{50\,\mathrm{J}}\)
Nur \(\fa{F}\cos\alpha = 25\,\mathrm{N}\) zieht längs des Weges.
Gleiche Zugkraft, halbe Arbeit: Der Rest zieht nach oben.
\(\fd{W} = \fa{F}\cdot s\cdot\cos\alpha = \fa{50\,\mathrm{N}}\cdot 2.0\,\mathrm{m}\cdot\cos 90^\circ = \fd{0\,\mathrm{J}}\)
Keine Kraft längs des Weges: keine Fläche.
Eine grosse Kraft heisst noch nicht, dass Arbeit verrichtet wird.
