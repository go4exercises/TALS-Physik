Wo liegt null auf der Kelvin-Skala?
Die Erkenntnisse zur Animation «Thermometer mit beiden Skalen»
\(T = \left(\frac{\fa{\vartheta}}{^\circ\text{C}} + 273.15\right)\mathrm{K}\)
Links Celsius, rechts Kelvin, am selben Rohr.
\(T = \left(\frac{\fa{\vartheta}}{^\circ\text{C}} + 273.15\right)\mathrm{K}\)
\({}= (-273.15 + 273.15)\,\mathrm{K} = \fd{0.00\,\mathrm{K}}\)
Die Kelvin-Skala beginnt beim absoluten Nullpunkt.
Tiefer geht es nicht.
\(T = \left(\frac{\fa{\vartheta}}{^\circ\text{C}} + 273.15\right)\mathrm{K}\)
\({}= (0.00 + 273.15)\,\mathrm{K} = \fd{273.15\,\mathrm{K}}\)
Die Celsius-Null ist nur ein Bezugspunkt.
Der Kelvin-Wert ist nie negativ.
\(T = \left(\frac{\fa{\vartheta}}{^\circ\text{C}} + 273.15\right)\mathrm{K}\)
\({}= (37.00 + 273.15)\,\mathrm{K} = \fd{310.15\,\mathrm{K}}\)
Man addiert immer dieselbe Zahl.
Beide Skalen: gleiche Striche, gleicher Abstand.
\(T = \left(\frac{\fa{\vartheta}}{^\circ\text{C}} + 273.15\right)\mathrm{K}\)
\({}= (100.00 + 273.15)\,\mathrm{K} = \fd{373.15\,\mathrm{K}}\)
Von \(0\,^\circ\text{C}\) bis \(100\,^\circ\text{C}\): auf beiden Skalen 100 Schritte.
\(\Delta T = 373.15\,\mathrm{K} - 273.15\,\mathrm{K} = 100\,\mathrm{K}\)
Gleiche Schritte, verschobener Nullpunkt.
\(T = \left(\frac{\fa{\vartheta}}{^\circ\text{C}} + 273.15\right)\mathrm{K}\)
\(0\,\mathrm{K}\) ist der absolute Nullpunkt, \(-273.15\,^\circ\text{C}\).
