Span oder Klotz?
Beide aus Aluminium — welcher ist dichter?
\(\fa{27\,\mathrm{g}} \quad\text{gegen}\quad \fa{2700\,\mathrm{g}}\)
Hundertmal mehr Masse — aber dichter?
\(\rho = \frac{\fa{m}}{\fb{V}}\)
Nicht «wie viel Masse», sondern «wie viel Masse je Volumen».
Ablesen lässt sie sich nie — man misst immer zwei Grössen einzeln.
\(\text{Span:}\quad \rho = \frac{\fa{27\,\mathrm{g}}}{\fb{10\,\mathrm{cm}^3}} = \fc{2.7}\,\frac{\mathrm{g}}{\mathrm{cm}^3}\)
\(\text{Klotz:}\quad \rho = \frac{\fa{2700\,\mathrm{g}}}{\fb{1000\,\mathrm{cm}^3}} = \fc{2.7}\,\frac{\mathrm{g}}{\mathrm{cm}^3}\)
Beide Zahlen wachsen um denselben Faktor — er kürzt sich weg.
\(1\,\frac{\mathrm{g}}{\mathrm{cm}^3} = \frac{10^{-3}\,\mathrm{kg}}{10^{-6}\,\mathrm{m}^3} = 10^{3}\,\frac{\mathrm{kg}}{\mathrm{m}^3}\)
\(2.7\,\frac{\mathrm{g}}{\mathrm{cm}^3} = 2700\,\frac{\mathrm{kg}}{\mathrm{m}^3}\)
Das Volumen gewinnt um tausend — daher der Faktor.
\(\text{in } \tfrac{\mathrm{g}}{\mathrm{cm}^3}: \quad \text{Wasser } 1.00 \qquad \text{Aluminium } 2.70\)
\(\text{Eisen } 7.87 \qquad \text{Gold } 19.30\)
Messen, teilen, nachschlagen — so verrät ein Ring, ob er wirklich aus Gold ist.
Die Dichte hängt an der Temperatur
\(\fb{V} \uparrow \quad\Longrightarrow\quad \rho = \frac{\fa{m}}{\fb{V}} \downarrow\)
Beim Erwärmen wächst das Volumen, die Masse bleibt — der Quotient wird kleiner.
Darum steht in Tabellen immer eine Temperatur dabei.
