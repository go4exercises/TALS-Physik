Die Erkenntnisse zur Animation «Wellenlänge, Frequenz, Geschwindigkeit»
\(\fd{\lambda} = \frac{\fa{c}}{\fb{f}}\)
\(\fa{c}\) gehört zum Medium, \(\fb{f}\) zum Sender.
\(\fd{\lambda} = \frac{\fa{c}}{\fb{f}} = \frac{\fa{2.00\,\mathrm{m/s}}}{\fb{1.0\,\mathrm{Hz}}} = \fd{2.00\,\mathrm{m}}\)
Von Berg zu Berg: \(2.00\,\mathrm{m}\) auf der Skala.
\(\fd{\lambda} = \frac{\fa{c}}{\fb{f}} = \frac{\fa{2.00\,\mathrm{m/s}}}{\fb{2.0\,\mathrm{Hz}}} = \fd{1.00\,\mathrm{m}}\)
Doppelte Frequenz, halbe Wellenlänge.
Die Welle wird kürzer, nicht schneller.
\(\fd{\lambda} = \frac{\fa{c}}{\fb{f}} = \frac{\fa{4.00\,\mathrm{m/s}}}{\fb{2.0\,\mathrm{Hz}}} = \fd{2.00\,\mathrm{m}}\)
Doppelte Geschwindigkeit, doppelte Wellenlänge.
Schneller wird die Welle nur durch das Medium.
\(\fd{\lambda} = \frac{\fa{c}}{\fb{f}} = \frac{\fa{6.00\,\mathrm{m/s}}}{\fb{4.0\,\mathrm{Hz}}} = \fd{1.50\,\mathrm{m}}\)
\(T = \frac{1}{\fb{f}} = \frac{1}{\fb{4.0\,\mathrm{Hz}}} = 0.25\,\mathrm{s}\)
\(\text{Probe: }\fd{\lambda}\cdot\fb{f} = \fd{1.50\,\mathrm{m}}\cdot\fb{4.0\,\mathrm{Hz}} = \fa{6.00\,\mathrm{m/s}}\)
Ein schnellerer Sender macht die Welle kürzer, nicht schneller.
\(\fa{c} = \fd{\lambda}\cdot\fb{f}\qquad T = \frac{1}{\fb{f}}\)
Die Geschwindigkeit gehört zum Medium.
