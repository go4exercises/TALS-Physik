Doppelt gespannt, doppelte Energie?
Die Erkenntnisse zur Animation «Spannenergie einer Feder»
\(\fa{E} = \frac{1}{2}\,D\,\fb{s}^2\)
Die Kraft wächst mit der Dehnung, die Energie noch schneller.
\(F = D\cdot \fb{s} = 800\,\mathrm{N/m}\cdot \fb{0.050\,\mathrm{m}} = 40.0\,\mathrm{N}\)
Die Kraft wächst linear: im Diagramm eine Gerade.
Das gilt im elastischen Bereich der Feder.
\(\fa{E} = \frac{1}{2}\,F\,\fb{s} = \frac{1}{2}\cdot 40.0\,\mathrm{N}\cdot \fb{0.050\,\mathrm{m}} = \fa{1.00\,\mathrm{J}}\)
Die Kraft steigt von null an: Es zählt nur das Dreieck.
Mit \(F = D\,s\) folgt \(\fa{E} = \frac{1}{2}\,D\,\fb{s}^2\).
\(\fa{E} = \frac{1}{2}\,D\,\fb{s}^2 = \frac{1}{2}\cdot 800\,\mathrm{N/m}\cdot (\fb{0.100\,\mathrm{m}})^2 = \fa{4.00\,\mathrm{J}}\)
Doppelte Breite, doppelte Höhe: vierfache Fläche.
\(\fb{s}\) verdoppelt, \(\fa{E}\) vervierfacht: \(\fa{E} \propto \fb{s}^2\).
\(\fa{E} = \frac{1}{2}\,D\,\fb{s}^2 = \frac{1}{2}\cdot 400\,\mathrm{N/m}\cdot (\fb{0.100\,\mathrm{m}})^2 = \fa{2.00\,\mathrm{J}}\)
Halbe Federkonstante: halbe Kraft, halbe Energie.
Beim Entspannen gibt die Feder die Energie wieder ab.
Doppelte Dehnung, vierfache Energie.
\(\fa{E} = \frac{1}{2}\,D\,\fb{s}^2\)
Die Energie ist die Dreiecksfläche unter \(F = D\,s\).
Proportional zu \(D\), quadratisch in \(\fb{s}\).
