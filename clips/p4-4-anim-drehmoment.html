Die Erkenntnisse zur Animation «Drehmoment, Hebelarm und Winkel»
\(\fd{M} = F\cdot l\cdot\sin\alpha\)
Dieselben 200 N drehen mal stark, mal kaum. Woran liegt das?
\(\fc{r} = l\cdot\sin\alpha = 0.50\,\mathrm{m}\cdot\sin(30^\circ) = \fc{0.25\,\mathrm{m}}\)
\(\fd{M} = F\cdot \fc{r} = 200\,\mathrm{N}\cdot \fc{0.25\,\mathrm{m}} = \fd{50.0\,\mathrm{N\,m}}\)
\(r\) ist das Lot von der Achse D auf die Wirkungslinie.
\(\fb{F_\perp} = F\cdot\sin\alpha = 200\,\mathrm{N}\cdot\sin(30^\circ) = \fb{100\,\mathrm{N}}\)
\(\fd{M} = \fb{F_\perp}\cdot l = \fb{100\,\mathrm{N}}\cdot 0.50\,\mathrm{m} = \fd{50.0\,\mathrm{N\,m}}\)
Zwei Wege, dasselbe Moment.
\(\fd{M} = F\cdot l\cdot\sin\alpha = 200\,\mathrm{N}\cdot 0.50\,\mathrm{m}\cdot\sin(90^\circ) = \fd{100.0\,\mathrm{N\,m}}\)
\(\sin 90^\circ = 1\): \(r = l\), das grösste Moment.
Bei \(30^\circ\) nur die Hälfte, denn \(\sin 30^\circ = 0.5\).
\(\fd{M} = F\cdot l\cdot\sin\alpha = 200\,\mathrm{N}\cdot 0.50\,\mathrm{m}\cdot\sin(0^\circ) = \fd{0\,\mathrm{N\,m}}\)
\(F_\parallel\) zeigt auf die Achse: Dieser Anteil dreht nicht.
Darum setzt man einen Schlüssel quer an, nie längs.
Nur der Anteil quer zum Hebel dreht.
\(\fd{M} = F\cdot \fc{r} = \fb{F_\perp}\cdot l = F\cdot l\cdot\sin\alpha\)
Grösstes Moment bei \(90^\circ\), keines bei \(0^\circ\).
