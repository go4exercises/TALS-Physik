Wie viel kommt nutzbar heraus?
Die Erkenntnisse zur Animation «Energiefluss eines Geräts»
\(\eta = \frac{\fc{E_\text{nutz}}}{\fa{E_\text{zu}}}\)
Gerechnet mit \(\fa{E_\text{zu}} = 100\,\mathrm{J}\) und typischen Werten.
\(\eta = \frac{\fc{E_\text{nutz}}}{\fa{E_\text{zu}}} = \frac{\fc{30\,\mathrm{J}}}{\fa{100\,\mathrm{J}}} = 30\,\%\)
\(\fd{E_\text{verl}} = \fa{E_\text{zu}} - \fc{E_\text{nutz}} = \fa{100\,\mathrm{J}} - \fc{30\,\mathrm{J}} = \fd{70\,\mathrm{J}}\)
Der grösste Teil wird Abwärme.
\(\eta = \frac{\fc{E_\text{nutz}}}{\fa{E_\text{zu}}} = \frac{\fc{5\,\mathrm{J}}}{\fa{100\,\mathrm{J}}} = 5\,\%\)
\(\fd{E_\text{verl}} = \fa{E_\text{zu}} - \fc{E_\text{nutz}} = \fa{100\,\mathrm{J}} - \fc{5\,\mathrm{J}} = \fd{95\,\mathrm{J}}\)
Eher eine Heizung, die nebenbei leuchtet.
\(\eta = \frac{\fc{E_\text{nutz}}}{\fa{E_\text{zu}}} = \frac{\fc{35\,\mathrm{J}}}{\fa{100\,\mathrm{J}}} = 35\,\%\)
\(\fd{E_\text{verl}} = \fa{E_\text{zu}} - \fc{E_\text{nutz}} = \fa{100\,\mathrm{J}} - \fc{35\,\mathrm{J}} = \fd{65\,\mathrm{J}}\)
Siebenmal so viel Licht wie die Glühbirne: \(\frac{35\,\%}{5\,\%} = 7\)
\(\eta = \frac{\fc{E_\text{nutz}}}{\fa{E_\text{zu}}} = \frac{\fc{92\,\mathrm{J}}}{\fa{100\,\mathrm{J}}} = 92\,\%\)
\(\fd{E_\text{verl}} = \fa{E_\text{zu}} - \fc{E_\text{nutz}} = \fa{100\,\mathrm{J}} - \fc{92\,\mathrm{J}} = \fd{8\,\mathrm{J}}\)
Immer \(\eta \lt 100\,\%\): Mehr als hineingeht, kommt nie heraus.
Was nicht genutzt wird, wird meist Wärme.
\(\fa{E_\text{zu}} = \fc{E_\text{nutz}} + \fd{E_\text{verl}}\)
Energie geht nicht verloren, sie wird nur unbrauchbar.
