Die Erkenntnisse zur Animation «Schaltung Schritt für Schritt zusammenfassen»
\(R_\mathrm{ges} = R_1 + \fa{R_2 \parallel R_3}\)
Zusammenfassen von innen nach aussen, rechnen von aussen nach innen.
\(R_1 = 100\,\Omega \quad R_2 = 220\,\Omega \quad R_3 = 330\,\Omega \quad U = 12.0\,\mathrm{V}\)
\(R_2\) und \(R_3\) teilen sich dieselben zwei Knoten: parallel.
Nicht \(R_1 + R_2\) rechnen, nur weil sie nebeneinander gezeichnet sind.
\(\fa{R_\mathrm{p}} = \frac{R_2 \cdot R_3}{R_2 + R_3} = \frac{220\,\Omega \cdot 330\,\Omega}{220\,\Omega + 330\,\Omega} = \fa{132.0\,\Omega}\)
Kleiner als der kleinste Einzelwiderstand: \(132.0\,\Omega < 220\,\Omega\)
\(\fb{R_\mathrm{ges}} = R_1 + \fa{R_\mathrm{p}} = 100\,\Omega + \fa{132.0\,\Omega} = \fb{232.0\,\Omega}\)
\(\fc{I} = \frac{U}{\fb{R_\mathrm{ges}}} = \frac{12.0\,\mathrm{V}}{\fb{232.0\,\Omega}} = \fc{51.72\,\mathrm{mA}}\)
Aussen angekommen: ein Widerstand, ein Strom.
\(U_1 = \fc{I} \cdot R_1 = \fc{51.72\,\mathrm{mA}} \cdot 100\,\Omega = 5.17\,\mathrm{V}\)
\(\text{Probe: } U_1 + U_\mathrm{p} = 5.17\,\mathrm{V} + 6.83\,\mathrm{V} = 12.00\,\mathrm{V}\)
\(\text{Probe: } I_2 + I_3 = 31.03\,\mathrm{mA} + 20.69\,\mathrm{mA} = \fc{51.72\,\mathrm{mA}}\)
Innen zusammenfassen, aussen beginnen zu rechnen.
\(U_1 + U_\mathrm{p} = U \qquad I_2 + I_3 = I\)
Eine Parallelgruppe ist kleiner als ihr kleinster Einzelwiderstand.
Gruppiert wird nach Knoten, nicht nach Zeichnung.
