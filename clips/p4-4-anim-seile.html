Wie stark ziehen die Seile?
Die Erkenntnisse zur Animation «Last an zwei Seilen»
\(\fb{S_1} = \frac{\fa{F_G}\cdot\cos\beta}{\sin(\alpha+\beta)}\)
Kann ein Seil mehr tragen müssen, als überhaupt dranhängt?
\(\fa{F_G} = m\cdot g = 8.0\,\mathrm{kg}\cdot 9.81\,\mathrm{m/s^2} = \fa{78.5\,\mathrm{N}}\)
\(\fb{S_1} = \frac{m g\cos\beta}{\sin(\alpha+\beta)} = \frac{8.0\,\mathrm{kg}\cdot 9.81\,\mathrm{m/s^2}\cdot\cos(45^\circ)}{\sin(90^\circ)} = \fb{55.5\,\mathrm{N}}\)
\(\fa{\vec F_G} + \fb{\vec S_1} + \fb{\vec S_2} = \vec 0\)
Aneinandergehängt schliessen sich die drei Pfeile.
Die senkrechten Anteile der Seile tragen zusammen \(F_G\).
\(\fb{S_1} = \frac{m g\cos\beta}{\sin(\alpha+\beta)} = \frac{8.0\,\mathrm{kg}\cdot 9.81\,\mathrm{m/s^2}\cdot\cos(15^\circ)}{\sin(30^\circ)} = \fb{151.6\,\mathrm{N}}\)
Fast das Doppelte der Last: \(1.9\cdot F_G\).
Ganz waagrecht spannen geht nie: Die Seilkraft wüchse ohne Grenze.
\(\fb{S_1} = \frac{m g\cos\beta}{\sin(\alpha+\beta)} = \frac{8.0\,\mathrm{kg}\cdot 9.81\,\mathrm{m/s^2}\cdot\cos(60^\circ)}{\sin(90^\circ)} = \fb{39.2\,\mathrm{N}}\)
\(\fb{S_2} = \frac{m g\cos\alpha}{\sin(\alpha+\beta)} = \frac{8.0\,\mathrm{kg}\cdot 9.81\,\mathrm{m/s^2}\cdot\cos(30^\circ)}{\sin(90^\circ)} = \fb{68.0\,\mathrm{N}}\)
Das steilere Seil trägt mehr.
Je flacher die Seile, desto grösser die Seilkräfte.
\(\fa{\vec F_G} + \fb{\vec S_1} + \fb{\vec S_2} = \vec 0\)
Eine Seilkraft kann die Last weit übersteigen.
