Die Erkenntnisse zur Animation «Zwei Widerstände in Reihe»
\(\fd{R} = \fb{R_1} + {R_2}\)
Ein einziger Weg für den Strom, durch beide nacheinander.
\(\fd{R} = \fb{R_1} + {R_2} = \fb{100\,\Omega} + {200\,\Omega} = \fd{300\,\Omega}\)
Der Strom muss durch beide Widerstände: Sie addieren sich.
\(I = \frac{U}{\fd{R}} = \frac{12.0\,\mathrm{V}}{\fd{300\,\Omega}} = 40.0\,\mathrm{mA}\)
Vor, zwischen und nach den Widerständen: überall \(40.0\,\mathrm{mA}\).
Unterbrichst du den Kreis an einer Stelle, fliesst nirgends mehr Strom.
\(\fb{U_1} = I\cdot \fb{R_1} = 0.0400\,\mathrm{A}\cdot \fb{100\,\Omega} = \fb{4.00\,\mathrm{V}}\)
\({U_2} = I\cdot {R_2} = 0.0400\,\mathrm{A}\cdot {200\,\Omega} = {8.00\,\mathrm{V}}\)
\(\fb{U_1} + {U_2} = 12.0\,\mathrm{V}\): doppeltes \(R\), doppelte Spannung.
\(I = \frac{U}{\fb{R_1} + {R_2}} = \frac{12.0\,\mathrm{V}}{\fb{100\,\Omega} + {300\,\Omega}} = 30.0\,\mathrm{mA}\)
Weniger Strom überall; \(\fb{U_1} = 3.00\,\mathrm{V}\) ; \({U_2} = 9.00\,\mathrm{V}\).
Jede Änderung wirkt auf den ganzen Kreis, auch auf \(R_1\).
In Reihe: ein Strom, geteilte Spannung.
