Die Erkenntnisse zur Animation «Je-desto-Explorer — Federdehnung»
\(x = \frac{\fa{m}\cdot g}{\fb{D}}\)
Immer nur eine Grösse aufs Mal ändern.
\(F = \fa{m}\cdot g = \fa{1.0\,\mathrm{kg}}\cdot 9.81\,\mathrm{m/s^2} = 9.81\,\mathrm{N}\)
\(x = \frac{F}{\fb{D}} = \frac{9.81\,\mathrm{N}}{\fb{25\,\mathrm{N/m}}} = 0.392\,\mathrm{m} = \fd{39.2\,\mathrm{cm}}\)
\(x = \frac{\fa{m}\cdot g}{\fb{D}} = \frac{\fa{2.0\,\mathrm{kg}}\cdot 9.81\,\mathrm{m/s^2}}{\fb{25\,\mathrm{N/m}}} = \fd{78.5\,\mathrm{cm}}\)
Doppelte Masse, doppelte Dehnung.
\(x = \frac{\fa{m}\cdot g}{\fb{D}} = \frac{\fa{2.0\,\mathrm{kg}}\cdot 9.81\,\mathrm{m/s^2}}{\fb{50\,\mathrm{N/m}}} = \fd{39.2\,\mathrm{cm}}\)
Doppelt so harte Feder: halbe Dehnung.
\(\fa{1.0\,\mathrm{kg}}\text{ an }\fb{25\,\mathrm{N/m}}:\quad x = \fd{39.2\,\mathrm{cm}}\)
\(\fa{2.0\,\mathrm{kg}}\text{ an }\fb{50\,\mathrm{N/m}}:\quad x = \fd{39.2\,\mathrm{cm}}\)
Zwei Änderungen zugleich: keine klare Wirkung.
Ursache: die Masse. Wirkung: die Dehnung.
