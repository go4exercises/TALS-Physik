\(\fa{c} = \frac{\fd{\lambda}}{\fb{T}}\)
Das Foto zeigt \(\fd{\lambda}\), der Mitschrieb \(\fb{T}\).
\(\fd{\lambda} = 2\,\mathrm{m}\qquad \fb{T} = 1\,\mathrm{s}\)
\(\fa{c} = \frac{\fd{\lambda}}{\fb{T}} = \frac{\fd{2\,\mathrm{m}}}{\fb{1\,\mathrm{s}}} = \fa{2\,\mathrm{m/s}}\)
Links Meter, rechts Sekunden.
\(\Delta s = \fa{c}\cdot \Delta t = \fa{2\,\mathrm{m/s}}\cdot 0.25\,\mathrm{s} = 0.5\,\mathrm{m}\)
Links wandert das Bild, rechts nur der Punkt.
Das Teilchen: \(y = -4.8\,\mathrm{cm}\).
\(\Delta t = \frac{\Delta s}{\fa{c}} = \frac{1\,\mathrm{m}}{\fa{2\,\mathrm{m/s}}} = 0.5\,\mathrm{s}\)
