Gleich schwer, gleich hoch: wer leistet mehr?
Die Erkenntnisse zur Animation «Hubleistung beim Heben»
\(\fb{P} = \frac{\fa{W}}{t}\)
Zwei Kisten, dieselbe Arbeit, verschiedene Zeit.
\(\fa{W} = m\,g\,h = 20\,\mathrm{kg}\cdot 9.81\,\mathrm{m/s^2}\cdot 1.5\,\mathrm{m} = \fa{294\,\mathrm{J}}\)
Masse und Höhe bestimmen die Arbeit, die Zeit nicht.
\(\fb{P} = \frac{\fa{W}}{t} = \frac{\fa{294\,\mathrm{J}}}{3.0\,\mathrm{s}} = \fb{98\,\mathrm{W}}\)
Gleiche Arbeit in gleicher Zeit: gleiche Leistung.
\(\fb{P} = \frac{\fa{W}}{t} = \frac{\fa{294\,\mathrm{J}}}{1.5\,\mathrm{s}} = \fb{196\,\mathrm{W}}\)
Die braune Kiste ist oben, die graue erst auf halber Höhe.
Halbe Zeit, doppelte Leistung.
\(\fb{P} = \frac{\fa{W}}{t} = \frac{\fa{294\,\mathrm{J}}}{6.0\,\mathrm{s}} = \fb{49\,\mathrm{W}}\)
Ein Watt ist ein Joule pro Sekunde: \(1\,\mathrm{W} = 1\,\mathrm{J/s}\).
\(49\,\mathrm{J}\) je Sekunde, sechs Sekunden lang: wieder \(\fa{294\,\mathrm{J}}\).
Gleiche Arbeit in kürzerer Zeit: mehr Leistung.
\(\fb{P} = \frac{\fa{W}}{t} = \frac{m\,g\,h}{t}\)
Die Hubarbeit hängt nicht von der Zeit ab.
\(1\,\mathrm{W} = 1\,\mathrm{J/s}\)
