Wohin geht die Energie beim Rutschen?
Die Erkenntnisse zur Animation «Energieerhaltung auf der Rutsche»
\(\fa{E_\text{pot}} + \fb{E_\text{kin}} = \fc{E}\)
Kind mit 30 kg, Reibung vernachlässigt.
\(\fa{E_\text{pot}} = m\cdot g\cdot h\)
\({}= 30\,\mathrm{kg}\cdot 9.81\,\mathrm{m/s^2}\cdot 2.0\,\mathrm{m} = \fa{588.6\,\mathrm{J}}\)
Im Balken gerundet: 589 J.
\(\fb{E_\text{kin}} = 0\,\mathrm{J}\): Das Kind steht noch.
\(\fa{E_\text{pot}} = m\cdot g\cdot h\)
\({}= 30\,\mathrm{kg}\cdot 9.81\,\mathrm{m/s^2}\cdot 1.0\,\mathrm{m} = \fa{294.3\,\mathrm{J}}\)
\(\fb{E_\text{kin}} = \fc{E} - \fa{E_\text{pot}} = 588.6\,\mathrm{J} - 294.3\,\mathrm{J} = \fb{294.3\,\mathrm{J}}\)
Die Balken zeigen gerundet je 294 J.
\(\fc{E} = \fa{E_\text{pot}} + \fb{E_\text{kin}} = 0\,\mathrm{J} + 588.6\,\mathrm{J} = \fc{588.6\,\mathrm{J}}\)
Unten: alles Bewegungsenergie.
Die Summe bleibt auf dem ganzen Weg gleich.
\(\fc{E} = m\cdot g\cdot h_0\)
\({}= 30\,\mathrm{kg}\cdot 9.81\,\mathrm{m/s^2}\cdot 3.0\,\mathrm{m} = \fc{882.9\,\mathrm{J}}\)
Im Balken gerundet: 883 J.
Lage wird Bewegung, die Summe bleibt.
\(E_\text{pot} + E_\text{kin} = \text{konstant}\)
Mit Reibung wird ein Teil zu Wärme.
