Die Erkenntnisse zur Animation «Kraftvektor und seine Komponenten»
\(\vec F \;\longrightarrow\; \fa{F_x}\,,\; \fb{F_y}\)
Wie viel der Kraft wirkt waagrecht, wie viel senkrecht?
\(\fa{F_x} = F\cdot\cos\varphi = 80\,\mathrm{N}\cdot\cos(35^\circ) = \fa{65.5\,\mathrm{N}}\)
\(\fb{F_y} = F\cdot\sin\varphi = 80\,\mathrm{N}\cdot\sin(35^\circ) = \fb{45.9\,\mathrm{N}}\)
\(\varphi\) zählt ab der positiven \(x\)-Achse, gegen den Uhrzeigersinn.
\(F = \sqrt{\fa{F_x}^2 + \fb{F_y}^2} = \sqrt{(\fa{65.5\,\mathrm{N}})^2 + (\fb{45.9\,\mathrm{N}})^2} = 80.0\,\mathrm{N}\)
Nicht \(65.5\,\mathrm{N} + 45.9\,\mathrm{N}\): Die Komponenten stehen rechtwinklig.
Die Zerlegung verliert nichts: Beide Teile ergeben wieder \(F\).
\(\fa{F_x} = F\cdot\cos\varphi = 80\,\mathrm{N}\cdot\cos(90^\circ) = \fa{0.0\,\mathrm{N}}\)
\(\fb{F_y} = F\cdot\sin\varphi = 80\,\mathrm{N}\cdot\sin(90^\circ) = \fb{80.0\,\mathrm{N}}\)
Bei \(0^\circ\) umgekehrt: \(F_x = F\) und \(F_y = 0\).
\(\fa{F_x} = F\cdot\cos\varphi = 80\,\mathrm{N}\cdot\cos(150^\circ) = \fa{-69.3\,\mathrm{N}}\)
\(\fb{F_y} = F\cdot\sin\varphi = 80\,\mathrm{N}\cdot\sin(150^\circ) = \fb{40.0\,\mathrm{N}}\)
Das Minus heisst: \(F_x\) zeigt nach links.
Das Vorzeichen liefert die Formel von selbst.
Eine Kraft, zwei Komponenten mit Vorzeichen.
\(\fa{F_x} = F\cos\varphi \qquad \fb{F_y} = F\sin\varphi\)
\(F = \sqrt{\fa{F_x}^2 + \fb{F_y}^2}\)
Winkel immer ab der positiven \(x\)-Achse messen.
